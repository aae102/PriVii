# Intern team backlog

Use pull requests against a shared integration branch. One designated engineering owner maintains contracts and merged demo quality.

1. Design system/navigation: consistent screens, responsive layout, accessibility, reusable input components.
2. Patient intake: validation, upload/file-preview simulation, source labels, encounter data contract.
3. Digital Care Team: editable brief, versioning, clinician confirmation, evidence distinctions.
4. Practice Signals: specialty and payer relevance; sources, dates and verified vs modeled financial impacts.
5. Action & Resolution: assignment, statuses, activity history, server-side readiness design.
6. Integration architecture: typed EHR and billing adapter boundaries, no fabricated live connection claims.
7. QA/security: end-to-end scripted FNP journey, synthetic data only, threat model, visual review.

Shared interfaces and stable IDs must be agreed before parallel implementations. Do not let interns independently invent conflicting data schemas.

Acceptance gate: intake → clinician brief → review → administrative task → completed status → dashboard update. Stage the FNP feedback session by December 18, 2026.
